# 0.2.1 - Cross

All collections of issues that we encounter and additional features that will be added for 0.2.2

## Windows Minecraft launch path fix
### What happened

Forge failed during startup because Windows can give the launcher an extended-length path such as `\\?\D:\data\game\...`. The launcher passed this path as the Minecraft game directory (`--gameDir`), and Forge's Java argument parser rejected the `?`, raising `InvalidPathException`.

### What changed

The launcher now normalizes paths when preparing arguments for Java. The helper is `java_path` in [`src-tauri/src/game.rs`](../src-tauri/src/game.rs):

```rust
fn java_path(path: &Path) -> String {
    let path = path.to_string_lossy();
    if let Some(unc_path) = path.strip_prefix("\\\\?\\UNC\\") {
        format!("\\\\{unc_path}")
    } else {
        path.strip_prefix("\\\\?\\").unwrap_or(&path).to_string()
    }
}
```

For a drive path, this turns `\\?\D:\data\game` into `D:\data\game` by removing the `\\?\` prefix. For an extended UNC path, it turns `\\?\UNC\server\share\game` into `\\server\share\game`, preserving the normal UNC prefix. If the path has no extended-length prefix, it is returned unchanged.

The launcher applies this conversion to Java-facing path arguments (including `--gameDir`, assets and native directories) and to the library/client JAR classpath entries. Rust still uses the original `Path` values for its own file operations; only the strings sent to Java are normalized.

Because these arguments are built in shared launch code, the fix also applies to Fabric, NeoForge, and other loaders that use that code. Linux and macOS paths are unchanged because they do not have the Windows `\\?\` prefix.

## Instance screenshots, worlds, and playtime
### What changed

The instance Content page now has **Screenshots**, **Worlds**, and **Playtime** tabs in addition to the existing installed content tabs.

- Screenshots in an instance's `screenshots` folder are shown in a gallery and can be saved from the page.
- Worlds in `saves` show their `icon.png` thumbnail when available. The NBT editor reads and writes `level.dat` as JSON; the first save keeps the original file as `level.dat.arca-backup`.
- Minecraft sessions are recorded per instance when the game process exits. The Playtime page shows the total and daily totals, using UTC dates. History starts accumulating after this update.

The UI is in [`src/content.tsx`](../src/content.tsx), and the instance file handling and playtime recording are in [`src-tauri/src/instance_features.rs`](../src-tauri/src/instance_features.rs), registered from [`src-tauri/src/main.rs`](../src-tauri/src/main.rs). The session recording hook is in [`src-tauri/src/game.rs`](../src-tauri/src/game.rs).

- `cargo check` passed.
- `RL Test` passed.
